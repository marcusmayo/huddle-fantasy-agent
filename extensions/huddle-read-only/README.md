# Withdrawn development companion

This experimental extension is not part of Huddle's product or setup. Do not install it. The user requires a self-contained app with its normal Yahoo account connection and no additional download.

These files remain solely as historical development evidence for the passive DOM reader and transport tests. Production rejects the companion pairing and delivery routes; development simulations retain them for regression coverage. The product no longer exposes connection-file or installation controls.

Earlier local 30- and 70-second rehearsals used a loopback DOM test transport. They do not establish live Yahoo performance or certify the replacement API-only path.
